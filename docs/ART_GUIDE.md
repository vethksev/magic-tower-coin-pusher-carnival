# 美術交件指南（Codex 用）

更新：2026-10-16。玩法同清單以 `docs/superpowers/specs/2026-10-16-magic-tower-coin-pusher-design.md` 第 3、4、8 節為準。

## 風格基準

- **彩色硬邊像素**：正方形像素、清楚像素群、無抗鋸齒、無模糊、無漸變光暈。遊戲用 nearest filtering，640×360 邏輯像素整數放大。
- **參考方向**：機台同幣嘅鮮色爽快感參考《RACCOIN: Coin Pusher Roguelike》；塔內石磚、火把、怪物、鑰匙、寶石參考經典《魔塔》（Tower of the Sorcerer）16×16 像素風但提升到本項目尺寸。
- **調色板**：每件素材 ≤ 12 實色；全項目共用一張主調色板（`assets/palette.png`，第一件素材通過時定案，之後所有素材必須取色自該板）。
- **alpha 只有 0 或 255**；alpha=0 嘅像素 RGB 必須清零（唔可以有隱藏光暈）。
- 唔抄任何現有遊戲嘅實際圖像；只參考風格。

## 尺寸規格

| 類別 | 邏輯尺寸 | 幀 | 備註 |
|---|---|---|---|
| 幣（20 款） | 16×16 | 2（待機、閃光） | 頂視碟仔，可見範圍 ≥ 13×13；每款輪廓／圖案要喺 16px 分得出 |
| 怪物（10 + 門衛） | 32×32 | 3（待機 ×2、受擊 ×1） | 底部對齊，pivot 中下 |
| 勇者頭像 | 32×32 | 1 | 側欄用 |
| 道具 icon（12） | 16×16 | 1 | |
| 機台 | 400×300 一整張背景 + 推板 1 張（寬 ~360 高 ~24）+ 發幣槽 2 張 | 推板 1 幀 | 塔門、邊坑要喺背景上有明顯視覺提示 |
| UI 面板／按鈕 | 9-slice 24×24 | 按鈕 2 態 | |

- 交件 PNG 一律邏輯尺寸原稿；另附 4× nearest 放大預覽（只做預覽，唔入 registry）。

## 交件流程

1. 一件一分支 `art/<item_id>`，例如 `art/coin_copper`。
2. 放入 `assets/<類別>/<item_id>/`：
   - `<item_id>.png`（原稿）
   - `<item_id>_x4.png`（預覽）
   - `prompt.md`（提示詞／來源／工具）
   - `qa.json`（尺寸、色數、alpha 檢查結果）
3. 更新對應 registry JSON（例如 `assets/coins/coins.json`）加一條：`{ "id": "coin_copper", "texture": "res://assets/coins/coin_copper/coin_copper.png", "frames": 2, "frame_w": 16, "frame_h": 16 }`。
4. 開 PR，附並排預覽（新素材放喺佔位圖旁邊、同其他已通過素材一齊顯示）。
5. **Owner 確認後**先 merge。被拒嘅方向刪圖檔同候選資料，唔留喺 repo。

## QA 檢查（交件前自己過）

- 尺寸正確、alpha 二值、透明區 RGB 為零、色數 ≤ 12 且全部來自主調色板。
- 4× 放大下無半透明邊、無孤立雜點。
- 幣：喺 16px 同 64px 兩個尺度都分得出係邊款。
- 怪物：3 幀 pivot 一致，受擊幀唔會跳位。

## 第一批次序

1. `coin_copper`（定調色板同碟仔輪廓）→ owner 確認 → 其餘 19 款幣。
2. 機台背景 + 推板（定機台材質）→ owner 確認。
3. 怪物第 1 層綠史萊姆 → 確認 → 其餘 10 隻。
4. 道具 icon、UI、音效。
